# 技术路线 v4（半年版）

> 前提：距离提交还有约 **6 个月**（到 2027 年 4—5 月）。
> 从"两周冲刺"改为"**月度里程碑**"：每月一个可验证的结论，月末复盘，不追进度、追结论。

## 0. 起点（2026-11 实测）

| 项目 | 数值 |
|---|---|
| 检测（960）val | 召回 68.9%、误合规 7.3%、FP 79 |
| 检测（960）test | 召回 67.0%、误合规 6.5% |
| 视频 R1 手部误检 | 32.5% 的帧 |
| 两阶段 | 三次不过门，已关闭 |
| 系统 | 无界面；跟踪/事件未做；视频素材 1 段 |

## 1. 半年后要交出什么

| 交付物 | 验收 |
|---|---|
| **一个能跑的系统** | 真实视频 → 检测 → 跟踪 → 事件 → 网页可看，3 分钟演示不碰代码 |
| **一套可复现的评测** | 回归集 ≥5 段视频、标注 ≥500 帧；一条命令出三个指标 |
| **一组可验证的改进** | 至少 2 个方向有前后对比（难例回灌、多帧融合），失败的也写清楚 |
| **材料** | 申报书、PPT、演示视频、答辩稿 |

## 2. 月度里程碑

| 月份 | 主题 | 交付 | 门（不过就调整，不硬推） |
|---|---|---|---|
| **M1（11 月）** | **地基** | 视频回归脚本；难例回灌实验；自采视频 ≥3 段 + 标注 ≥150 帧 | 回灌后 FP 79→≤60 且召回 ≥67.9%；回归脚本能复现 32.5% |
| **M2（12 月）** | **视频闭环** | 跟踪 + 事件聚合；三种融合规则消融 | 事件级误报 ≤ 帧级 1/5；出三规则对比表 |
| **M3（1 月）** | **语义边界** | 骑行盔/网兜帽负样本；是否启用"大框拒识器"的验证 | 语义类误检占 FP ≤10%；拒识器在预测框裁片上 head→helmet <5% 才启用 |
| **M4（2 月）** | **系统** | Web 终端：上传/实时画面、事件列表、统计、阈值设置 | 端到端跑通，3 分钟演示 |
| **M5（3 月）** | **加固** | seed 复现（均值±范围）、跨场景泛化测试、消融汇总 | 关键结论在 2 个 seed 上成立；跨场景掉点 ≤8 个点 |
| **M6（4—5 月）** | **材料** | 申报书、PPT、演示视频、答辩演练 | 模拟答辩 2 轮 |

## 3. 每月节奏

```text
每周：一次 30 分钟同步，只看"本周做了什么、下周做什么"
每次实验：填实验卡片（假设 / 最小验证 / 失败判据 / 结果 / 结论）
每月末：复盘三问 —— 这个月验证了什么？哪条走不通？下个月改什么？
```

**半年里最重要的一条**：每月至少产出一个"能被数据证明或证伪"的结论。宁可结论是负的，也不要一个月只写了代码。

## 4. 资源与风险

| 风险 | 时间点 | 应对 |
|---|---|---|
| 期末考试 | 1 月、6 月 | 1 月只排"轻任务"：负样本、文档整理 |
| 寒假 | 2 月 | 适合集中做系统（M4），但要在放假前定好分工 |
| GPU 只有 8 GB | 全程 | 一次只跑一个训练；960 单轮约 90 分钟，排夜间 |
| 数据采集许可 | 随时 | 提前联系场地；没有许可就用公开工地视频，但要注明来源 |
| 组员流动/懈怠 | 全程 | 每月里程碑绑定具体人；做不完就缩范围，不延 deadline |

## 5. 明确不做（半年内）

| 不做 | 理由 |
|---|---|
| 换检测框架、自研主干 | 半年也做不出可信消融，且与"能演示"冲突 |
| 多路摄像头管理、报表导出、权限系统 | 功能堆砌 |
| 人脸识别、反光背心等扩展 | 超出选题范围 |
| 云端部署、实时推流 | 局域网单机足够演示 |

## 6. 半年后的作品长什么样

一个**局域网内的网页系统**：

- 上传一段工地视频 → 自动分析 → 画面里画出头与安全帽；
- 右侧事件列表：谁、什么时候、哪一帧、抓拍图、状态（违规 / 待复核）；
- 能按时间筛选、能点开看大图、能导出一次分析结果；
- 背后有一份"我们试过什么、什么有效、什么无效"的实验记录。

**答辩讲的故事**：不是"我们用了 YOLO"，而是"我们发现误报有两种、漏检有一种，分别用什么办法压住了多少，哪些办法试过但无效"。
