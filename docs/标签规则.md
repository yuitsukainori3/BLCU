# 安全帽数据集标签规则（head / helmet）

> 版本：v1.2（2026-11-01）
> 适用范围：本项目所有安全帽检测数据，包括团队标注的小数据集和后续重标的大数据集。
> 规则变更必须升版本号，并同步给所有标注成员；旧标签按新版本返工时，在 `docs/` 里记一笔。
>
> **v1.2 删除 `person` 类**，只保留 `0 head`（裸头）和 `1 helmet`（安全帽）。现有 150 张图的
> `person` 行已全部删除（train 386 行、val 147 行），`data.yaml` 改为 `nc: 2`。
> 需要“人”框时不在本模型里标，改用 COCO 预训练的 YOLO11 单独检测 `person`，两路结果在业务层合并。
>
> （v1.1 只改过类别 ID 顺序：`0 head`、`1 helmet`、`2 person`，与当时的标签文件对齐。）

## 0. 一分钟版

- 两个类别，顺序固定：`0 head`、`1 helmet`。
- **同一个头，`helmet` 和 `head` 只能二选一**，不能都标，也不能都不标（看不清的除外）。
- `helmet` 只表示**戴在头上**的安全帽；拿在手里、放地上、挂墙上的安全帽**不标 helmet**。
- `helmet` / `head` 只框头部，不框脖子和肩膀。
- 模型预标注只是底稿，**每一个框都必须人工确认或修改**。

## 1. 类别定义

| ID | 名称 | 标注对象 | 不要标 |
|---|---|---|---|
| 0 | `head` | **没有佩戴劳保安全帽**的头部（含头发、脸、耳朵；便帽、头巾、骑行头盔也归此类） | 已经戴了安全帽的头 |
| 1 | `helmet` | **戴在头上**的劳保安全帽（hard hat），颜色不限 | 手持、放地上、挂墙上的安全帽；棒球帽、头巾、骑行头盔 |

两条硬约束：

1. `helmet` / `head` 在同一颗头上互斥：同一颗头只能出现其中一个框。
2. 类别 ID 必须和 `data.yaml` 的 `names` 顺序一致：`head=0`、`helmet=1`。

## 2. 判定总表

| 画面情况 | helmet | head | 说明 |
|---|---|---|---|
| 戴好安全帽 | ✓ | ✗ | 同一个头只标 `helmet` |
| 没戴安全帽，头部可见 | ✗ | ✓ | 同一个头只标 `head` |
| 手里拿着安全帽，头是裸的 | ✗ | ✓ | 帽子拿在手里不算 `helmet` |
| 安全帽放在地上 / 挂在墙上 | ✗ | 裸露的头照常标 `head` | 帽子本身不标 |
| 戴帽但严重遮挡、看不清 | 能确认是安全帽就标，否则不标 | ✗ | 不设 ignore 类，见 6.5 |
| 背对镜头但能看到安全帽 | ✓ | ✗ | 只看到安全帽背面也算 `helmet` |

## 3. 框怎么画

### 3.1 通用

- 一个目标一个框；框贴住目标可见边缘，不留大片背景（边距控制在几个像素内）。
- 框不能互相合并：两个人贴在一起，也要各自的头盔/头部各一个框。
- 同一个目标不允许出现两个框（重复标注按错误处理）。
- 目标被画面边缘截断时，按**可见部分**画框；坐标保持 0–1，框中心不要落到画面外。
- 坐标统一用归一化值：`x_center y_center width height`，都除以图片宽高。
- 标注过程中**不要旋转、裁剪、缩放原图**，否则坐标会错位；需要预处理就统一在标注前做完并留档。

### 3.2 helmet / head

- 只框头部：`helmet` 框安全帽本体，`head` 框裸露的头部；都不要框到脖子、肩膀。
- 遮挡时只框可见部分，不把被遮挡的区域补进来。
- 图像边缘只露出半个头/半个安全帽：按可见部分标，前提是能判断它是什么。
- 同一张图里，每个人头要么有 `helmet`、要么有 `head`，逐个人头检查。
- 远距离、小尺寸的头也要标，只要还能明确判断是头（最小尺寸见第 7 节）。

## 4. 颜色与样式

- 安全帽颜色（黄、红、白、蓝、橙等）不影响类别，一律 `helmet`。
- 安全帽上的反光条、logo、编号不影响类别。
- 口罩、护目镜、耳罩不影响类别。

## 5. 容易判错的情况

| 情况 | 正确做法 | 常见错误 |
|---|---|---|
| 手拿安全帽、头裸露 | 标 `head`，不标 `helmet` | 把帽子标成 `helmet` |
| 安全帽放地上 / 挂墙上 | 不标 `helmet` | 把物体安全帽标成 `helmet` |
| 戴了棒球帽 / 头巾 / 长发遮头 | 标 `head` | 当成 `helmet` |
| 骑行头盔、施工用普通帽子 | 标 `head`（不算劳保安全帽） | 当成 `helmet` |
| 戴帽但严重遮挡 | 能确认就 `helmet`，否则不标 | 同时标 `helmet` 和 `head` |
| 同一颗头两个框 | 删掉多余的，只留一个 | 重复框 |

## 6. 边界情况（v1.2 执行细则）

以下情况原规则表没有覆盖，按这里执行；团队确认不同做法后，改本节并升版本。

### 6.1 帽子与头部遮盖

- 棒球帽、渔夫帽、头巾、连帽衫帽子、长发遮住头顶：一律 `head`，视为未佩戴安全帽。
- 安全帽反戴、没扣下颚带、戴歪：只要戴在头上，仍标 `helmet`；本版本不区分“是否规范佩戴”。
- 安全帽 + 口罩/护目镜/耳罩：照常 `helmet`。

### 6.2 只看到部分身体

- 头在画面外、只露出身体：**不标**（本模型只认头）。
- 只露出一颗头、看不到身体：照常标 `helmet` / `head`。
- 只露出一只手或一条腿：不标。

### 6.3 多个目标

- 一个人戴帽、旁边另一个人裸头：一个 `helmet`，一个 `head`。
- 人抱着孩子、两人重叠：两个头分别判断，各标一个。
- 画面里有很多远处的头：按第 7 节的最小尺寸规则处理，能标尽标。

### 6.4 非真人

- 海报、广告牌、电视/手机屏幕、镜子与玻璃反光里的人像：不标。
- 假人模特、雕塑、卡通形象：不标。
- 水印、台标、文字：不标。

### 6.5 “看不清”怎么处理

YOLO 没有 ignore 类，本项目也**不新增 `ignore` 类**。统一处理：

- 能判断是安全帽 → 标 `helmet`；
- 能判断是裸头 → 标 `head`；
- 完全无法判断 → 不标这个头，并在该图的备注里记一笔；
- 如果整张图都不可用（严重模糊、过曝、遮挡），这张图**不进验证集和测试集**，训练集里也尽量剔除。

## 8. 标签文件格式与目录

### 8.1 文件对应

- 标签文件必须与图片**同名同目录结构**：`images/train/0001.jpg` ↔ `labels/train/0001.txt`。
- 图片改名时，标签文件必须同步改名；不允许只改一边。
- 一个图片对应一个 txt；没有目标的图片也要有空 txt（本项目应尽量避免纯背景图）。

### 8.2 每行格式

```text
class_id x_center y_center width height
```

示例（左边一个人戴帽，右边一个人裸头）：

```text
1 0.300000 0.240000 0.115000 0.130000
0 0.720000 0.260000 0.090000 0.130000
```

要求：

- 一行一个目标，空格分隔，不要表头、不要注释、不要空行；
- 坐标均为 0–1 的归一化值，保留 6 位小数即可；
- `width`、`height` 必须大于 0；
- 类别 ID 只能是 `0`、`1`。

### 8.3 目录结构

```text
small_dataset/
  images/
    train/
    val/
  labels/
    train/
    val/
  data.yaml
```

`data.yaml` 已按本规则配置：

```yaml
path: F:/Competition/ultralytics-8.3.163/ultralytics-8.3.163/datasets/small_dataset
train: images/train
val: images/val

nc: 2
names: ['head', 'helmet']
```

训练脚本实际读的是 `ultralytics/cfg/datasets/smalldata.yaml`，它指向同一个目录，两处
`names` 必须一致。`0make_dataset/small_dataset/` 下那份是抽样脚本的产出目录（目前是空的），
不要拿来当训练路径。

## 9. 标注流程

1. **逐头检查**：先把图里所有头过一遍，每颗头问一句“戴了吗”，选 `helmet` 或 `head`。
2. **互斥自查**：同一颗头不能同时出现 `helmet` 和 `head`。
3. **保存后自查**：txt 行数 = 画面里头的数量；类别 ID 没写错。
4. **模型预标注只做底稿**：预标注出来的框要逐个确认，错框删掉、漏框补上，不允许直接采用。
5. **每 50 张互查 5 张**：两人交叉看，分歧当场记下来并统一口径。
6. **验证集/测试集纯人工**：任何伪标签、预标注未修改的图都不能进 val / test。

## 10. 交付前检查清单

- [ ] 没有同一个头同时出现 `helmet` 和 `head`。
- [ ] 没有把手持/地上的安全帽标成 `helmet`。
- [ ] 没有把棒球帽、骑行头盔标成 `helmet`。
- [ ] 没有重复框、没有漏框（特别检查画面边缘和远处）。
- [ ] 所有坐标在 0–1 之间，宽高大于 0。
- [ ] 标签里**没有 class_id 2**（`person` 已于 v1.2 废弃）。
- [ ] 图片和标签文件名一一对应，train/val 没有串。
- [ ] 类别统计合理：`helmet` 与 `head` 的比例和现场实际接近，偏差大就抽查。
- [ ] `data.yaml` 是 `nc: 2`、`names: ['head', 'helmet']`，和标签里的 class_id 对得上。
- [ ] 抽查 10% 交叉复核，记录分歧。
