# 本地小样本训练试跑记录

## 目的

这次试跑用于确认最新仓库的 YOLO11 训练脚本、两类类别映射和演示前端能否在本机 GPU 上工作。数据不是最新 SHWD 划分，因此这份结果不用于宣称超过 GitHub 上的 SHWD 基线，也不能证明已达到计划书的目标。

## 数据与设置

- 数据：团队既有两类人工标注小样本；70 张训练、30 张验证。
- 标签：从旧三类标签保留 `0=head`、`1=helmet`，移除 `person` 类；验证集不参与训练。
- 验证标注：114 个目标，其中 head 5 个（集中在 3 张图）、helmet 109 个。
- 初始化权重：YOLO11n 通用预训练权重。
- 输入尺寸：960；训练 60 轮；batch 4；seed 42；Ultralytics 8.3.163。
- 硬件：NVIDIA GeForce RTX 5070 Laptop GPU，8 GB；PyTorch 2.11.0+cu128。
- 结果目录：`runs/train/local_70_30_yolo11n_9604/`；最终验证：`runs/val/local_demo_best_val/`。

## 验证结果

| 类别 | Precision | Recall | AP50 | AP50-95 | 验证框数 |
|---|---:|---:|---:|---:|---:|
| head | 0.964 | 0.600 | 0.695 | 0.426 | 5 |
| helmet | 0.952 | 0.780 | 0.901 | 0.482 | 109 |
| 总体 | 0.958 | 0.690 | 0.798 | 0.454 | 114 |

head 只有 5 个验证目标，召回 0.600 相当于 3 个检出、2 个漏检；每个目标都会明显影响指标。样本量太小，数值只能说明当前训练流程可运行，不能作为可靠的现场能力结论。当前没有为这批数据保留独立 test 划分。

## 端到端冒烟运行

用 GitHub 的 SHWD v0.1.0 权重处理一段本地 1080p、349 帧短视频，每 2 帧推理一次，同时调用 COCO 人体 ByteTrack。整段处理链路完成，输出 `runs/demo_video_helmet_v010.mp4`（约 83 MB），视频源帧处理速度约 21.7 帧/秒。共得到 39 个检测框，但没有形成可关联到人员的 head/helmet 观察，也没有违规事件；因此这次只证明视频读取、模型调用、跟踪调用和标注视频编码能跑通，**不代表视频场景已识别成功或现场佩戴合规**。

## 下一步有效实验条件

需要把 GitHub 记录所用的 SHWD 两类数据本地准备好（2,274 train / 282 val / 662 test），然后固定原始划分与阈值，依次比较 640/960、原始采样/`head` 重复采样和时序策略。优先报告 head 召回、误合规率、分尺度召回、推理耗时和事件级误报；最终模型只在 test 上做一次评估。
