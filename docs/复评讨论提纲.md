# 复评讨论提纲（组内用）

> 用途：组会 15 分钟过完，最后要拍三个板。
> 背景：老师 11-02 晚的回复 + 复评评分表（创 / 量 / 健 / 技 / 美，各 20%）

## 一、老师说了什么

| 老师原话 | 我们的理解 |
|---|---|
| YOLO11 检测较常见，创新点不突出 | 用现成模型不算错，错在**没有一处是我们改的** |
| 技术路线可行，但难点和解决方案不突出 | 要说清“哪个问题难、怎么解、解完好了多少” |
| 需要突出技术难点，而不是技术堆叠 | **别加模块**，加一个就要能证明一个 |
| 至少形成一个能验证的技术改进点 | **一个就够**，但必须有前后对比 |
| 双路 vs 联合：先做基线比较再定 | 不是让我们现在拍板，是让我们拿数据说话 |
| 必须用真实或自采连续视频测试 | 硬要求，不能只做单张图片 |
| 突出核心特色、避免功能堆砌 | 只留四件：识别、告警、事件闭环、可视化 |

评分表里老师圈了 **创 20%** 和 **技 20%**——这两项我们现在的材料几乎是空的。

## 二、我们现在的位置（实话实说）

**已经有的：**

- 数据：SHWD 2,274 训练 / 282 验证 / 662 测试，两类 `head` / `helmet`
- 基线：mAP50 0.8207，违规召回 58.9%，误合规 7.3%
- 一个自己测出来的问题：**head 召回随尺寸从 82.9%（>60px）掉到 11.1%（<15px）**
- 评测体系：分层表（尺寸 / 亮度 / 拥挤度）+ 错误分解 + 难例图

**缺的：**

- 一个**方法层面**的改进点（现在全是“训练 + 评测”）
- 一段**自采视频**（跟踪、投票、事件级指标都做不了）
- 界面还没开始

## 三、要拍板的三件事

### 议题 1：创新点押哪个？

| 方案 | 是什么 | 优点 | 风险 |
|---|---|---|---|
| **A 两阶段解耦** | 检测只负责找头，裁片分类器负责判戴没戴 | 直接打我们测出的问题；3 天出结果；有前后对比 | 分类器也可能错，收益不确定 |
| B 切片推理 | 大图切块检测，小目标更清楚 | 工程感强，好讲 | 更像调参，创新性弱 |
| C 分层评测体系 | 把评测方法本身当贡献 | 素材已有 | 老师大概率不认，这是分析不是方法 |

**建议选 A。** 理由：它是唯一一个“针对我们自己的数据发现”的方法改进。

### 议题 2：双路 vs 联合，做不做对比？

- 现状：**SHWD 没有 person 标注**，联合模型训不了，做不了公平对比。
- 选项 1：补 150—200 张 person 标注（约 3 小时），再做对照实验。
- 选项 2：暂不做，文档里写清“数据不含 person 标注，待补标注后验证”。

**建议选 2**，把 3 小时给视频。老师说的是“先比较再定”，不是“必须现在比”。

### 议题 3：视频怎么拍？

- 谁去拍？有没有工地 / 实训场地的进入许可？
- 拍什么：**至少 3 段**——白天正常作业、远景小目标、人群密集；有条件再加夜间。
- 每段 30 秒以上，最好固定机位。
- 验收：能跑出“帧级告警数 vs 事件级告警数”的对比。
