## 1. 一句话 + 全景

**一句话**：检测器负责"找到头"，复核分类器负责"判断戴没戴"，中间按目标大小分流。

```text
视频帧
  │
  ├─ 检测模型（YOLO11s，960 输入，两类 head / helmet）
  │      └→ 头部候选框 + 检测器给的类别
  │
  ├─ 按框大小分流
  │      ├─ <30 px      → 直接用检测器的判定（裁片太糊，分类器帮不上）
  │      ├─ 30—60 px    → 分类器有把握才改
  │      └─ >60 px      → 分类器判定优先（误判集中在这一档）
  │
  ├─ 跟踪（ByteTrack）+ 连续帧投票
  │
  └─ 事件：抓拍 + 记录 + 告警（同一个人连续违规才算一次）
```

目前**检测部分已完成，两阶段与跟踪待做**。下文所有数字都标了状态。

## 2. 三个设计决策（为什么这么做）

### 2.1 为什么用 SHWD、只做两类

- 我们最初只有 150 张自有图（105 训练 / 45 验证），训出来的模型在验证集上 `head` AP 只有 0.47——**样本太少，测不出改进**；
- SHWD 是公开安全帽数据集（MIT 许可），清洗后有 **2,274 张训练 / 282 验证 / 662 测试**，场景是工地/作业现场，和我们的目标一致；
- 只做 `head`（裸头）和 `helmet`（安全帽）两类：这两类互斥（一颗头要么戴要么不戴），判定逻辑最干净。`person` 类需要额外的标注，且 SHWD 没有，暂时不做。

> 诚实说明：数据是公开数据集，不是我们现场拍的；"场景吻合"指的是都是工地类图片，不等于真实工地部署验证。

### 2.2 为什么先做"分层评测"，而不是直接调模型

因为**一个总分会骗人**。

我们一开始只看 mAP，觉得 0.82 "还行"。做分层之后才发现：`>60px` 的裸头召回 82.9%，`<15px` 只有 **11.1%**——总分把巨大的差距平均掉了。

分层评测就是按**目标尺寸 / 光照 / 拥挤度**把验证集切开，分别算召回和误合规。它是后面所有判断的尺子：

- 改分辨率，看小目标那两档涨没涨；
- 改分类，看大目标那档的误合规降没降；
- 三档都没动、只有总分涨 0.01 → 大概率是噪声。

### 2.3 为什么用 960，以及它"证明"了什么

`imgsz` 从 640 提到 960，召回从 58.9% 涨到 68.2%。但**真正有价值的不是涨点，而是错误结构的变化**：

| 错误类型 | 640 | 960 | 变化 |
|---|---:|---:|---:|
| 判对 | 89 | 104 | +15 |
| **误合规（判成戴帽）** | **11** | **11** | **0** |
| 低置信（看见了不敢报） | 18 | 8 | −10 |
| 定位偏差 | 5 | 3 | −2 |
| 完全没检出 | 28 | 25 | −3 |

**分辨率把"看不清"和"没看见"解决了一部分，但"看见却判错"的 11 个一个都没动。**

这就证明了：**检测能力和判别能力是两件事**，可以分开优化。两阶段方案就是从这个结论来的，不是拍脑袋加的模块。

## 6. 组员最常问的八个问题

**Q1：mAP 0.85 算好吗？**
不算差，但没用。我们关心的是"违规召回 68.2%"和"大目标误合规 9.8%"——这两个才对应产品体验。mAP 只适合横向比模型，不适合对外讲故事。

**Q2：为什么不用我们自己那 150 张？**
样本太少（105 张训练），训出来 `head` AP 只有 0.47，而且测不出改进。现在它们作为"另一套来源"保留，暂不参与训练。

**Q3：为什么要两个模型？不是一个模型判两类吗？**
检测器是"一个模型判两类"，但它同时要定位和分类，小目标上顾不过来。分类器只做"看特写判戴没戴"，任务更简单，能补上前者的短板。实测 960 之后误合规 11 个没变，就是证据。

**Q4：分类器和检测器冲突时听谁的？**
按尺寸分流：小框听检测器的（裁片太糊），大框听分类器的（有把握就改），中间档看分类器有没有把握。这个规则就是我们的"创新点"。

**Q5：为什么有 val 还要 test？**
val 用来调参和选模型，test 只在最后跑一次。**拿 test 调过参，最终数字就不可信了。**

**Q6：用了 YOLO 是不是就没创新了？**
评委不看你用没用 YOLO。看的是"有没有一处是你自己的、并且能被数据证明有效"。我们的创新在判定流程（按尺寸路由的两阶段），不在网络结构。

**Q7：训练要多久？机器够不够？**
640 约 29 分钟、960 约 90 分钟（RTX 5060 8G）。注意两点：`cache="ram"` 时 Windows 必须 `workers=0`，否则内存会被复制爆；显存只剩 8G，别同时跑两个训练。

**Q8：数据能商用吗？**
SHWD 是 MIT 许可，标注和代码可商用；但图片是网络抓取的（含图库水印），对外展示要注意。文档里要注明来源。
