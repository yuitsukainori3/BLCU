# 筑安慧眼展示系统使用说明

## 当前可演示内容

展示页采用 Streamlit 单机运行，上传本地授权视频后，使用项目的两类 YOLO11 权重检测 `head / helmet`，并调用 COCO 人体模型提供跟踪 ID。系统将人员框上部作为头部关联区域，对已关联目标进行滑窗投票与告警冷却，生成疑似违规事件；同时统计每个区域的头部观测和佩戴率。

分区风险使用指数平滑：新观测占 30%，上一次风险占 70%。某区域近期违规比例上升时，风险权重会升高；后续观测到佩戴情况改善时，权重会逐步回落。这个权重用于演示提醒优先级，不等同于现场安全评价或处罚结论。

页面支持调整 `head / helmet` 两类置信度、抽帧间隔、投票长度和违规比例门槛，并导出标注视频和事件 CSV。模型只输出候选，事件处置状态需要人工复核。

## 启动

在项目根目录的 PowerShell 中执行：

```powershell
python -m venv --system-site-packages .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

如果已按仓库说明把 Ultralytics 8.3.163 上游源码放在 `ultralytics-8.3.163/ultralytics-8.3.163/`，页面会优先使用该源码版本。PyTorch 请按照机器显卡从 PyTorch 官方页面单独安装。

## 正式训练改进模型

训练集需要符合当前 SHWD 两类标签定义：`head=0` 表示未戴安全帽的头，`helmet=1` 表示佩戴安全帽的头。只有一个 `head` 类、把安全帽合并为头部的旧数据不能用于这个任务。

```powershell
python scripts/train_improved.py --data datasets/shwd/data.yaml --model yolo11s.pt --imgsz 960 --epochs 120
```

可选的训练集少数类重复采样：

```powershell
python scripts/build_balanced_dataset.py --data datasets/shwd/data.yaml --repeat 2
python scripts/train_improved.py --data runs/data/head_repeated/helmet_head_repeated.yaml --name helmet_head_repeated
```

重复采样仅适用于训练集。消融比较时应保持验证集、测试集、评估口径一致，并报告未戴帽召回率、误合规率、mAP、推理时延和事件级误报；采样或增强的收益都需要实测。

## 已知限制

- 最新仓库不跟踪数据集；本地需先按数据说明准备 `datasets/shwd/`。
- 两路逐帧推理包含人员模型和安全帽模型，负载较高；页面通过抽帧降低处理速度压力。
- 目前输入为上传的视频，不是 RTSP 摄像头接入；事件写入当前会话并可导出 CSV，尚无持久数据库、登录权限或领导/区域负责人消息推送。
- Git LFS 权重需成功下载后才能推理；应用会检查模型大小和清单 SHA256，避免误用指针或损坏文件。
