# 公开数据集调研（安全帽 / 头部）

> 日期：2026-11-01
> 目的：当前自有数据只有 150 张（train 105 / val 45），裸头仅 79 框、19 张图，需要外部数据补 `head`。
> 原则：只写查到的事实，每条都附来源；没有核实的内容标“待核实”。

## 0. 结论

| 优先级 | 数据集 | 一句话 |
|---|---|---|
| 1 | **SHWD（VOC2028）** | 类别就是「安全帽 / 裸头」，MIT 许可，7,581 张，最对口 |
| 2 | Kaggle `mystorts/helmet-detection` | YOLO 格式现成、9,636 张、三类，但**许可未知**，只能内部用 |
| 3 | Roboflow *Hard Hat Workers*（已在用） | 只有 head 一类，没有 helmet，只能补“头”，补不了“帽” |

三个都必须配一条红线：**验证集/测试集只用团队自己拍的图**，公开数据不进 val。

## 2. SHWD（Safety-Helmet-Wearing-Dataset）

**来源**：[GitHub njvisionpower/Safety-Helmet-Wearing-Dataset](https://github.com/njvisionpower/Safety-Helmet-Wearing-Dataset)，1.7k stars，MIT License（GitHub API 返回 `license.spdx_id = MIT`）。

| 项 | 数值 |
|---|---:|
| 图片 | 7,581 张 |
| 标注框 | 120,558 个 |
| `hat`（戴帽） | 9,044 |
| `person`（**裸头**，非人体） | 111,514 |
| 格式 | Pascal VOC XML，`ImageSets/Main` 里有 train / val 划分 |
| 场景 | 建筑工地、户外施工、厂区，含遮挡、远近差异、逆光、密集人群 |

**关键注意点**

1. **类名会骗人**：`person` 指的是“没戴帽的头”，不是“人”。映射到我们的规范就是 `hat → 1 helmet`、`person → 0 head`。
2. **负样本有域外数据**：README 写明部分裸头来自 [SCUT-HEAD](https://github.com/HCIILAB/SCUT-HEAD-Dataset-Release)（教室/室内人头），和工地场景差异大。混进来会拉偏 `head` 的分布。
3. **正负比 1 : 12**：裸头远多于安全帽。直接全量训练，模型会倾向于把什么都判成 head（对我们来说方向是“宁可误报”，可以接受，但要在自有 val 上复核）。
4. **下载**：数据不在仓库里，走 README 里的百度网盘 / Google Drive 链接（2019 年发布，可能失效）。国内也有第三方转好 YOLO/COCO 格式的版本（如[这篇博客](https://www.cnblogs.com/LimiiiingCV/articles/22872472)介绍的 VOC2028 整理版），用第三方版本时仍以原仓库为引用来源。

## 3. Kaggle `mystorts/helmet-detection`

**来源**：[kaggle.com/datasets/mystorts/helmet-detection](https://www.kaggle.com/datasets/mystorts/helmet-detection)（通过 Kaggle API 读取元数据）。

| 项 | 数值 |
|---|---:|
| 图片 | 9,636（train 6,533 / val 2,128 / test 975） |
| 标注框 | 130,431 |
| `helmet` | 105,680 |
| `no_helmet` | 18,966 |
| `person` | 5,785 |
| 格式 | YOLO txt |
| 体积 | 1.88 GB |
| 许可 | **Unknown**（元数据 `licenseName: "Unknown"`） |
| 更新 | 2026-01-19 |

**优点**：格式现成、类别命名干净（`no_helmet` 就是裸头）、数量足够、自带 train/val/test。
**问题**：**没有明确许可，也没有写明数据来源**（描述里只说“来源于公开工业场景图像”）。这种数据在竞赛里可以拿来做预训练或内部对比实验，但**不能写成“自采数据”，也不能声称是我们标注的**；最终提交的材料里如果用到，要注明来源不明、仅用于模型预训练。

## 4. 怎么接进现有项目

1. **类别映射**
   - SHWD：`hat → 1`，`person → 0`
   - Kaggle：`helmet → 1`，`no_helmet → 0`，`person`（全身框）**丢弃**
2. **过滤（重要）**
   - 丢掉“一张图里 0 个 helmet 框”的图：SHWD 里这些多半是 SCUT-HEAD 的教室头，域不匹配；同时也能压一压裸头占比。
   - 抽查 20 张过滤后的图，确认都是工地/作业场景。
3. **划分红线**
   - 公开数据只进 train；
   - val / test 只用团队自己的图（现在是 45 张，建议先扩到 150 张）。
4. **训练配比**
   - 第一版：自有 105 张 + SHWD 过滤后 1,000—1,500 张，`imgsz=960`，其余超参不动；
   - 训练完只看两件事：自有 val 上 `head` 的 AP 有没有从 0.469 涨，`helmet` 有没有掉。

## 5. 风险

| 风险 | 说明 | 应对 |
|---|---|---|
| 域偏移 | SHWD 多是远景/人群，我们的图偏近景 | 自有 val 上逐类看，掉点就减配比 |
| 教室人头混入 | SCUT-HEAD 部分 | 按「图内有 helmet」过滤 + 抽查 |
| 许可 | Kaggle 那份 Unknown | 只用于预训练，最终材料注明来源 |
| 标注噪声 | 公开集标注质量参差 | 不拿公开数据当 test；训练时开 mosaic/mixup 抗噪 |
