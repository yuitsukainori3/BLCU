## 2. SHWD 下载后的实测（2026-11-01）

下载位置：`F:\Competition\0make_dataset\VOC2028\VOC2028`（Annotations 7,581 / JPEGImages 7,581）。

### 2.1 结构：其实是两份数据拼起来的

| 分组 | 图片 | hat 框 | person（裸头）框 | 场景 |
|---|---:|---:|---:|---|
| 带安全帽的图 | **3,219** | 9,047 | 1,453 | 工地、作业现场、产品图 |
| 无安全帽的图 | **4,362** | 0 | **110,061** | 基本是 SCUT-HEAD 的教室/室内人头 |

- 也就是说：**98.7% 的“裸头”来自教室人头**，和工地不是一个域。
- 真正可用的工地部分只有 3,219 张，其中裸头仅 1,453 个。
- 另有 17 个源文件夹（`tmp`、`img`、`hat01`、`Img_2000`、`500pic` 等），带帽的主要来自 `tmp`/`img`/`hat01`。

### 2.2 质量问题（抽查发现）

1. **错标**：`000032.jpg` 是一家人在客厅合影，全员戴着白色安全帽，却被标成 `person`（裸头）。
2. **漏标**：工地门口照片 `hat01_000299.jpg` 里，背景中几个人完全没有框。漏标会让模型学会“这里没有人”，比错标更伤。
3. **图库水印**：大量图片带有“汇图网/昵图网”等水印，说明是网络抓取；MIT 许可覆盖的是仓库里的标注和代码，不等于图片本身可以随意使用。
4. **产品特写混入**：部分图是安全帽的产品展示图/拼图（例如 8 格展示同一个人戴不同配件），有 50 个 hat 框覆盖超过半张图。

### 2.3 结论

- **helmet 部分可用**（9,045 个框，场景接近），能补“头盔样式”的多样性；
- **head 部分（教室人头）不要混进训练**，会教模型把室内正面人脸当成“工地裸头”；那 110k 框看着诱人，实际是另一个任务。

## 3. 已经做好的转换

脚本：[`0make_dataset/convert_shwd.py`](../0make_dataset/convert_shwd.py)（VOC XML → YOLO，`hat→1 helmet`、`person→0 head`）。

```bash
python 0make_dataset/convert_shwd.py                       # 默认：只转带 hat 的图，标签 + 图片列表
python 0make_dataset/convert_shwd.py --materialize hardlink  # 图片也放进来（同盘硬链接，不占空间）
```

当前实际使用的布局（用 `--materialize hardlink` 生成，3,218 张图全部是硬链接，磁盘占用 0）：

```text
F:\Competition\datasets\shwd\
  data.yaml          # nc: 2, names: ['head', 'helmet']
  images/train       2,274 张（硬链接到 VOC2028\JPEGImages）
  images/val           282 张
  images/test          662 张
  labels/{train,val,test}/*.txt
  preview/*.jpg      # 6 张画好框的样例，用来肉眼检查
  train.txt/val.txt/test.txt   # 同上三组的绝对路径，不放图片时用这个
```

不加 `--materialize` 时只写 `labels/` 和三个 `.txt` 列表，`data.yaml` 指向列表文件，Ultralytics 也能直接读。


实测产出：**3,218 张图 / 9,045 个 helmet / 1,453 个 head**（2 个过小的框被丢弃，4,363 张无帽图按默认跳过）。
用 `ultralytics.data.utils.check_det_dataset()` 验证过：`nc=2`、`names={0: head, 1: helmet}`，三个列表都能解析。

## 4. 怎么用

### 4.1 先单独训一版，验证这份数据“能不能迁移”

```bash
# 工作目录：ultralytics-8.3.163/ultralytics-8.3.163/
yolo detect train model=yolo11s.pt data=F:/Competition/datasets/shwd/data.yaml \
  epochs=50 imgsz=640 batch=16 workers=4 device=0 project=runs/detect name=shwd_only
```

训完**用我们自己的 45 张 val 测**（不是 SHWD 的 val），命令：

```python
from ultralytics import YOLO
m = YOLO("runs/detect/shwd_only/weights/best.pt")
r = m.val(data="smalldata.yaml", workers=0, device=0)
print(r.box.ap50)   # [head, helmet]
```

### 4.2 判据

| 结果 | 说明 | 下一步 |
|---|---|---|
| 自有 val 上 helmet ≥ 0.85 | 说明能迁移 | 混进训练集，做 4.3 |
| helmet < 0.7，head 一塌糊涂 | 域差太大 | 只挑工地子集，或放弃 |
| head 明显被带偏（把室内脸认成头） | 说明仍然学到了教室分布 | 减少 SHWD 比例 / 只保留带帽图 |

### 4.3 混合训练（等 4.1 有结论再做）

- 自有 105 张 + SHWD 2,274 张（train）按 1:3 到 1:5 混；
- 自有 45 张 val 保持纯净，绝不混入；
- 先跑 `imgsz=960`、`patience=30`，看 head 有没有从 0.469 往上走。

## 5. 风险

| 风险 | 说明 | 应对 |
|---|---|---|
| 域偏移 | 教室人头占 98.7% 的 head 框 | 默认过滤，不混入 |
| 漏标 | 背景里的人没框 | 抽查；训练时靠 mosaic/mixup 缓解，但不能根治 |
| 错标 | 白帽被标成裸头 | 人工抽查 50 张，发现成片错的批次整批丢 |
| 版权 | 图库水印、网络抓取 | 只用于训练，不对外展示原图；文档注明来源 |
| 许可 | Kaggle 那份 Unknown | 只在预训练里用，提交材料注明 |
