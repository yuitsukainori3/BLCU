# 筑安慧眼 · 初期方案

**——基于 YOLO11 的工地安全帽佩戴检测与 Web 管理终端**

## 一、选题

我们要做的是：**用工地现有的摄像头，自动发现没有戴安全帽的人，并把结果做成一个给工地管理层用的网页终端。**

选这个题，是因为安全帽检查目前基本靠人工巡查、班前检查和抽查：作业面分散、人员流动，很难持续盯住；夜间、远处、逆光时人眼也看不清；真出了违规，往往只有口头提醒，缺少能回看的记录。工地上摄像头本来就有，缺的是“看得过来”的那一层。

对我们来说，重点不是刷指标，而是把成熟的检测模型用到工地场景里，把误报压住，把系统做成能演示、能交付的东西——这也是我们作为本科生团队比较现实的目标。

## 二、目标

分三层：

1. **检测**：用 YOLO11 训练安全帽佩戴检测模型，区分“戴了安全帽”和“没戴（裸头）”。
2. **匹配**：检测出画面里的人，把头框归到具体某个人，回答“是谁没戴”。人这一路用现成的 COCO 还是联合模型，还没定，第三节再说。
3. **呈现**：做成网页管理终端，看画面、出告警、留记录。

**跑基线时，我们发现了一个现象。** 把输入分辨率从 640 提到 960，漏检少了一批，召回上去了；但 151 个裸头里，“裸头被判成戴了”（误合规）的那部分，11 个还是 11 个，一个没少。按框的大小分层看，小目标的召回最低，而大目标的误判最多（640 基线）。

这说明“没看见”和“看错”是两件事，提高分辨率只能救前者。我们觉得这里有一个值得做的难点：**同一个检测头既要找得全，又要判得准，这两个目标在阈值上互相拉扯；模型也没有为“判错”单独优化的通道。** 大目标明明看得清，却仍然被判错，这类错误换更大的模型、更高的分辨率都不一定有用。

**我们的想法：把“找”和“判”分开。** 检测器先用 960 输入、把置信度放宽，尽量把头都找出来；再按框的大小决定谁来判：小于 30 px 的框保留检测器结果（裁片太小，分类器不可靠）；30—60 px 的框，分类器有把握才覆盖；大于 60 px 的框分类器优先（640 基线上这一档误判最多，裁片也最清楚）。分类器是 224 输入的轻量模型，只判“戴 / 没戴”。目前裁片已经做好，分类器刚起步，还没接进推理，也没做端到端验证。

## 三、准备怎么做

**1）数据**
以公开安全帽数据集为主（例如 SHWD），先跑通训练流程；再用团队自采或公开视频补充工地场景，按场景划分训练集和验证集，避免同一段视频的相邻帧同时进两边。

**2）模型**
用 YOLO11 的 s 规模做迁移学习，只设“戴 / 不戴”两类，一颗头只出一个框——框的数量就是头的数量，框的类别就是结论。先跑基线，再根据误报和漏检补数据。

**3）人—头盔匹配**
人这一路现在有两个选择：一是直接用 COCO 预训练的 person，不重新训练，先按这个跑；二是训练一个联合模型，一个模型同时出 person、helmet、head 三类框。前者省标注；后者部署简单，但缺 person 标注，暂时训不出可信的版本。头框归到人的规则不变：取 person 框上部当头部区域，头框中心落在谁的区域就归谁；归不上的单独记录，不参与投票。到底用哪个，等数据补上再比。

**4）判定与去抖**
单帧结果只作为候选：同一个人在连续多帧里都被判为“没戴”才告警，同一个人短时间内不重复报。判定输出“戴了 / 没戴 / 待复核”三种状态；分数落在中间、目标太小或遮挡严重时进待复核，不硬判成合规。参数先给经验值，之后用现场视频标定。

**5）系统**
后端负责拉流、推理、判定和存事件；前端是网页，负责画面、告警、事件和统计。先做单机版，跑在局域网里的一台机器上，不依赖云。

验证先用自采的几段连续视频跑通检测、跟踪、投票、事件的全链路；视频上主要看事件级指标——事件数、重复告警、漏报，而不只是逐帧对不对。

## 四、最终成品大概什么样

一个**网页**，管理层用浏览器打开、登录就能用，不用装客户端：

- **实时监控**：多路摄像头画面，画面里画出检测框；有违规时，对应画面和右侧告警卡片同时提示。
- **告警**：每条告警带抓拍截图、时间、摄像头，可以点“已处理”或“误报”；同一处违规在多帧里只算一条事件，不重复刷屏。
- **事件中心**：按时间、摄像头、状态查历史记录，点开看大图。
- **统计**：按天、按摄像头看违规趋势，可导出表格。
- **设置**：增删摄像头、调阈值、切换模型版本。

## 五、范围与边界

- 只做安全帽佩戴这一件事；不做人脸识别、身份与考勤，不做反光背心等其他劳保用品，也不做跨摄像头追踪。
- 定位是“辅助提醒”，不替代现场安全管理；夜间、强逆光、远距离和严重遮挡不承诺稳定识别。
- 不确定时转“待复核”，不把“没检测到”当成“已合规”。
- 拍摄现场画面前要取得管理方许可，对外材料里的人脸打码，现场视频不外传。

## 六、大致阶段

1. 数据与基线模型：把两类模型训出来，能在一批图上给出可信的结果；
2. 判定逻辑：把人和头两路接起来，做归属和多帧投票，先在离线视频上跑通；
3. Web 终端：摄像头接入、告警、事件、统计；
4. 联调与演示：用自采视频回归，准备答辩演示。
