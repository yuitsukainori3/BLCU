# 评测记录

> 数据口径：SHWD 自己的划分（train 2,274 / val 282 / test 662），两类 `0 head` / `1 helmet`。
> **val 用来调参和消融，test 只在最后跑一次**，不要拿 test 选模型。
> 误合规率 = 真值 head 被判成 helmet 的框数 ÷ 真值 head 总框数（对安全帽系统来说最不能接受的错误方向）。
>
> 由 `scripts/eval_report.py --append` 自动追加。

|---|---|---|---|---:|---:|---:|---:|---:|

| 2026-11-01 21:01 | train4 | test | 640 | 0.8138 | 0.5925 | 0.6834 | 0.9441 | 7.7% |

## 基线说明

- `train4` = SHWD train 2,274 张、640 输入、50 轮，是本套结构下的第一条基线；
- val 与 test 差 0.007（mAP50），说明两个划分同分布，test 可以作为最终报告用；
- 违规召回（val）：89 / 151 = 58.9%；误合规 11 / 151 = 7.3%。

## 基线分层（train4 / val / 640）

分层表由 `eval_report.py` 自动输出，这里只摘最关键的尺寸维度：

| head 框尺寸 | 数量 | 违规召回 | 误合规 |
|---|---:|---:|---:|
| <15 px | 18 | 11.1% | 0.0% |
| 15—30 px | 41 | 46.3% | 4.9% |
| 30—60 px | 51 | 66.7% | 5.9% |
| >60 px | 41 | 82.9% | 14.6% |

- 尺寸是压倒性因素：召回从 82.9% 掉到 11.1%；
- 亮度三档（<80 / 80—110 / >110）召回 61.1% / 56.9% / 59.8%，**没有明显差异**；
- 拥挤度三档 65.3% / 55.3% / 56.4%，**约 9 个点的轻微影响**。
