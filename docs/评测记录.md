## 分类器与两阶段（P0，2026-11-04）

| 项目 | 结果 |
|---|---|
| 分类器 `cls_v1`（30 轮，7,902 训练裁片） | val top1 **97.24%**、top5 100% |
| 裁片级混淆 | head 判对 88%、**判成 helmet 12%**；helmet 判对 99%、判成 head 1% |
| 两阶段（margin 0.2 与 0.3 结果相同） | 违规召回 **68.9% → 67.5%**、误合规 **7.3% → 8.6%** |
| 改判数 | 15 个（改对 6、改错 3） |
| 结论 | **未过 G1**：分类器整体偏向 helmet，反而制造了新的误合规 |

**失败原因（初步）**：训练裁片 head 1,766 vs helmet 6,136（1:3.5），模型整体准确率被多数类主导；且 head 裁片中位 35×44、helmet 80×98，缩放后清晰度不同，模型可能学到“越糊越像头盔”的捷径。

|---|---:|---:|---:|

分层（head）：

| 尺寸 | 640 召回 | 960 召回 | 变化 |

- 小目标两档（59 个框）召回从 35.6% 提到 52.5%；
- `>60 px` 的误合规 14.6% → 9.8%，提高分辨率没有牺牲大目标；
- 代价：训练 30 → 90 分钟，单张推理 5.3 → 18.2 ms（约 3.4 倍）；
- 唯一变差：`<15 px` 的误合规 0% → 16.7%（3/18）。

## 基线说明

- `train4` = SHWD train 2,274 张、640 输入、50 轮，是本套结构下的第一条基线；
- val 与 test 差 0.007（mAP50），说明两个划分同分布，test 可以作为最终报告用；
- 违规召回（val）：89 / 151 = 58.9%；误合规 11 / 151 = 7.3%。
