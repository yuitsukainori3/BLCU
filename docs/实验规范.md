# 实验规范（团队约定）

> 定于 2026-11-04，起因见 [复盘](复盘_2026-11-04.md)：两阶段方向花了约 2 小时 GPU 才发现不成立。
> 适用范围：所有模型训练、策略调整、判定逻辑改动。**写完代码不算完成，跑完门才算。**

## 一、三条铁律

### 1. 30 分钟证伪

动手前必须能回答三句话，答不出第 3 句就不做：

1. **假设**是什么（一句话）；
2. **最小验证**是什么（一小时内能跑完）；
3. **什么结果算失败**（写死数值）。

### 2. 先比基线

任何新组件（新模型、新判定、新阈值）接入系统前，必须与**"不接它"的基线**在**同一子集**上比较。

- 比不过就不接，不解释、不加补丁、不"再调调看"；
- 比较必须在**真实使用分布**上做（例：分类器要在**预测框**裁片上比，不是在 GT 框裁片上比）。

### 3. 视频回归

每次模型更新，跑固定视频，记录三个数：

- 手部 / 非头目标误检次数（按位置聚簇计数）
- `head` 检出总数
- 平均单帧耗时

固定素材：`datasets/Pexels_11798561_workers_steel_frame_HD.mp4`（736 帧、1280×720、50 fps）。
基线值（`helmet_v0.1.0`，imgsz 960、conf 0.05、head 阈值 0.18）：手部误检 **276 次**、head 检出 **308 次**。

## 二、指标：一主两护栏

| 角色 | 指标 | 口径 |
|---|---|---|
| **主** | 违规召回（裸头判对率） | val 282 张，conf 0.25、IoU 0.45，逐框匹配 |
| 护栏 1 | 误合规率 | 真值 head 被判 helmet ÷ 真值 head 总数，同上口径 |
| 护栏 2 | 视频手部误检次数 | 固定视频，按位置聚簇计数 |

**任何实验只报这三个数。** 中途换指标 = 自欺。

### 口径备注

- `eval_report.py`（混淆矩阵）与 `error_analysis.py`（逐框匹配）会差 1 个框（103 vs 104），**对外统一用混淆矩阵**；
- test 只在最终版本跑一次，中间对比一律用 val；
- 视频指标不受 conf 阈值以外的参数影响，报告时必须注明阈值。

## 三、实验卡片

每次实验在下方表格追加一行。**没填"失败判据"的，不许开工。**

| 日期 | 假设 | 最小验证 | 失败判据 | 结果 | 结论（接/不接） |
|---|---|---|---|---|---|
| 11-04 | 裁片复核能降低误合规 | 分类器 + 尺寸路由跑 val | 误合规 >5% 或召回 <66.2% | 召回 68.2%、误合规 7.9% | **不接** |
| 11-04 | 用预测框裁片训练可对齐分布 | cls_v3 端到端 | 同上 | 68.2% / 7.9% | **不接** |

## 四、门的写法

统一格式，写在任务开始前：

```
G<编号>：<指标> 从 <现值> 到 <目标>；否则 <动作>
```

例：

```
G1：误合规率从 7.3% 到 ≤5%，且召回不低于 66.2%；否则转"不确定态"备选，停止投入。
```

## 五、复盘节奏

每次实验结束后，在实验卡片后补三行：

1. 预期是什么；
2. 实际是什么；
3. 差在哪、下一步做什么。

**一句话也行，但不能空着。** 空着就等于这次实验白做。
